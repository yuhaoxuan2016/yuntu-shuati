# 小兔错题本（网页版）

智能题库练习应用 - 导入即刷 - AI 自动解析 - 多人考试 - 云端同步

基于 Vue 3 + Vite 6 + PWA 构建，支持 Word 题库导入、多种练习模式、多人在线考试、遗忘曲线记忆复习、错题本与云端同步。
开发过程中使用了 AI 编程工具辅助开发。

> 本项目基于 [MYT6666](https://github.com/MYT6666) 的 shuati-bao 项目二次开发，详见文末致谢。

## 功能特性

### 题库与练习

- **Word 题库导入**：从 .docx 导入题目，AI 自动解析题型与答案（需用户自配 API Key）
- **公共题库**：云端官方题库在线直读，一键导入为私人副本后享完整功能
- **多种练习模式**：顺序练习、随机练习、错题重练，支持选项乱序（判断题永不乱序）
- **多题型支持**：单选、多选、判断、填空、问答题，导入时自动识别（微信小程序端目前只有单选/多选/判断三类）
- **学习计划**：今日进度、正确率、连续刷题天数一屏可见

### 考试系统

- **模拟考试**：自定义考试时长、题量、及格线，考试进度自动保存（刷新不丢）
- **多人考试**：创建考试并分享链接，考生答题后实时汇总成绩，支持限时开放
- **智能组卷**：按等级 × 题型配额随机组卷，一键生成综合大考
- **混合抽题**：从多个题库随机抽题组成练习
- **查询码回看**：考试结果凭查询码跨设备回看

### 记忆与错题

- **错题本**：自动收录错题，考试错题可手动加入
- **自动掌握**：连续答对 N 次（可配置 2/3/5 次或关闭）自动移入已掌握
- **顽固错题**：累计做错次数统计，重点攻克反复出错的题目
- **记忆复习**：基于遗忘曲线的间隔重复，自动评估记忆强度与健康度

### 云端与数据

- **云同步**：基于腾讯云 CloudBase 的双向同步（增量同步、并发提速），题库/进度/错题/收藏/设置全覆盖
- **账号打通**：填入小程序生成的绑定码，即可把网页端从匿名身份切换为与小程序共用的账号，错题与进度两端互通，可随时解绑
- **本地备份**：一键导出 JSON（题库与学习数据；AI 密钥等本机凭据不写入备份），跨设备迁移完整恢复
- **公共题库管理**：自由建公共题库已关闭，提交公共题库需管理员审核

### AI 能力（BYOK 模式）

- **AI 详细解析**：题目一键 AI 解析
- **AI 识别引擎**：Word 导入的题目解析
- 说明：网站本身不内置 AI 服务，以上功能需用户在设置页自行配置个人第三方大模型 API Key（兼容 OpenAI 兼容接口，如 DeepSeek、阿里百炼等）

### 界面与体验

- **10 套主题色** × 明暗双模式，自由组合
- **字号调节**：整体缩放，适配不同视力需求
- **PWA**：添加到手机主屏幕，离线可用，刷新不丢设置

`npm run build` 产出纯静态的 `dist/`，可部署到任意静态托管。

## 云同步配置（可选）

应用默认以纯本地模式运行（数据存 IndexedDB）。如需云同步：

1. 注册[腾讯云 CloudBase](https://cloud.tencent.com/product/tcb) 并创建环境
2. 在应用「设置」页面填入环境 ID（envId）
3. 默认使用匿名登录，每个设备是独立身份（换浏览器或清缓存会丢数据）。如需跨设备/跨端保持同一身份，在小程序「我的 → 与网页版打通」生成 6 位绑定码（10 分钟内有效、仅可使用一次），填入本应用「设置」页即可切换为与小程序共用的账号

构建者也可以通过 `.env` 配置默认云端环境（`VITE_DEFAULT_CLOUD_ENV_ID`，格式见 `.env.example`）。配置后，未手动填写 envId 的访客会自动连接该环境，零配置浏览公共题库与公共考试（只读，可复制为私人副本）；不配置则为纯本地模式。

> 云同步仅同步个人题库和练习进度，公共题库由服务端管理。私人数据（错题/收藏/进度/私人题库）仅本人可见。

## 个人资源说明

以下文件属于维护者的个人 / 品牌素材，**未包含在仓库中**，克隆后请自行准备或替换：

| 文件 | 用途 | 建议替换内容 |
|------|------|-------------|
| `public/wechat-qr.png` | 「联系我」二维码 | 你自己的微信二维码图片 |
| `public/contact-avatar.png` | 联系人头像 | 任意头像图片 |
| `public/logo*.png`、`public/logo.gif`、`public/icons/logo-*.gif` | 站点 logo（含主题色动图） | 你自己的图标 |
| `public/share-card.png` | 社交分享卡片（`og:image`） | 自行绘制 |
| `public/mp-qr.png` | 小程序码 | 你自己的小程序码 |

**全部缺失也不影响构建与运行**：logo 缺失时页面自动收起图片、只留站名；头像 / 二维码缺失时回落到随仓库发布的占位件（`public/placeholders/*.png`）；分享卡片缺失时构建会自动把 `og:image` 指向占位件。
